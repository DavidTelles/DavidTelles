## 🚀 Featured Projects

### 🎬 Cineflow

A web app for exploring, searching and viewing details about movies and TV series, using data from the TMDB API. It has a home feed with catalog rows, a search page, detail pages with cast and recommendations, a trailer modal and light/dark themes. All TMDB requests go through the app's own API routes, so the access token stays on the server.

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `TMDB API`

**[Repository](https://github.com/DavidTelles/Cineflow) · [Live demo](https://cineflow-mu.vercel.app)**

### 💰 Fintrack

A personal finance tracking app, currently in early development. I'm using it to practice working with a relational database through an ORM and to implement authentication from scratch.

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `Drizzle ORM` `PostgreSQL (Neon)` `Zod`

**[Repository](https://github.com/DavidTelles/Fintrack)**
